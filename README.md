Nastavení v Arduino IDE:

Instalace jádra (pokud ještě nemáte):

V levém panelu otevřete Boards Manager (druhá ikona shora).

Vyhledejte balíček Arduino Mbed OS Nano Boards a nainstalujte ho.

Výběr desky:

V horní liště vyberte z nabídky desek: Arduino Nano RP2040 Connect.

K tomu přiřaďte příslušný COM port (např. COM3).
